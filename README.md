# Reproducible Research: Study Time and Academic Performance

## Research Question

Does study time have an association with students' final exam performance?

## Objective

The objective of this project is to demonstrate a reproducible and preregistered statistical analysis.

## Hypothesis

Students with higher study time are expected to have higher final exam scores.

## Main Analysis

The primary analysis uses Pearson correlation.

A linear regression is used as a secondary analysis.

## Repository Structure

- `preregistration.md` – Preregistered analysis plan
- `environment.yml` – Computational environment
- `data/raw/` – Raw dataset
- `data/interim/` – Intermediate data
- `data/processed/` – Processed data
- `notebooks/` – Analysis notebook
- `src/` – Analysis code
- `tests/` – Synthetic pipeline tests
- `reports/` – Final report

## Reproducibility

This repository contains:

1. A preregistration document
2. A reproducible environment specification
3. A structured data pipeline
4. Analysis code
5. Synthetic pipeline tests
