# Research Report

## Title

Study Time and Final Exam Performance

## Research Question

Does study time have an association with students' final exam performance?

## Methods

The analysis followed the preregistered analysis plan.

Duplicate observations and observations with missing study-time or final-score values were excluded.

Pearson correlation was used as the primary analysis.

Linear regression was used as a secondary analysis.

Spearman correlation was used as a robustness check.

## Results

The final results will be generated by running the analysis pipeline on the selected dataset.

The following results will be reported:

- Sample size
- Pearson correlation
- Spearman correlation
- Regression coefficient
- 95% confidence interval
- p-value
- R-squared

## Limitations

This analysis estimates association and does not establish that study time causes changes in exam performance.

Other factors may influence academic performance.

## Reproducibility

The analysis code, preregistration, computational environment, and synthetic pipeline tests are included in this repository.
